Everything an AI agent needs to know to use Nexus Pro effectively in a workspace environment. Updated live from the running server.

Overview

Nexus Pro is an MCP server that sits between your AI agent and its LLM API calls. Its primary purpose is token cost reduction — without changing the quality of outputs.

Prompt Compression

Strip irrelevant sections from system prompts. 20–50% input token savings per call.

Session Memory

Distill sessions to ~45-token snapshots. Eliminates expensive context replay on cold start.

Drift Detection

Detect repetition loops and goal misalignment early. Stop wasting tokens before they compound.

Cost Analytics

Session-level token tracking with compression rates and estimated USD cost saved.
